# GS Claw Egg - Vue 3 Mockup

Prototype game flow based on the provided GS Claw Game mockup.

## Included
- 10 Points per play
- Unlimited plays while Points are sufficient
- 10-second round timer
- Auto-claw when time expires
- Left/right claw movement
- Mobile shake (DeviceMotion) to stir eggs
- Desktop fallback “กวนไข่” button
- Tap repeatedly to crack egg with progressive crack sprite
- Weighted mock reward draw
- Coin balance accumulation
- Responsive mobile UI
- Custom assets already included in `src/assets`
- SVG crack sprite sheet with 8 frames

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL.

> iOS motion sensor may require HTTPS and explicit permission from the user.
